# Kiswani Brand Web

Apply the official Kiswani Lights identity consistently while adapting it for accessible, responsive digital experiences.

## Start with the source material

1. Read [references/brand-system.md](references/brand-system.md) for every branded task.
2. Read [references/website-blueprint.md](references/website-blueprint.md) for website, catalog, product-page, navigation, SEO, or CMS work.
3. Inspect `../../../Kiswani Guidelines 2026.pdf` when exact logo construction, clear space, or a visual example matters.
4. Use images in `assets/` as visual references only. Request the original production logo files before launch if they are not present in the project.

## Apply the workflow

1. Identify the page type, audience, content priority, and language direction.
2. Establish the approved color and type tokens before styling components.
3. Choose the vertical or horizontal bilingual logo lockup according to available space.
4. Build the first viewport around lighting, atmosphere, and a clear product or catalog action.
5. Extend the identity with editorial whitespace, yellow rules, dark panels, rounded white content frames, premium interior photography, and outlined lighting icons.
6. Support Arabic RTL and English LTR as first-class layouts rather than mirrored afterthoughts.
7. Validate responsiveness, keyboard use, contrast, loading performance, metadata, and logo integrity before delivery.

## Preserve these non-negotiables

- Preserve the logo's aspect ratio, bilingual lockup, construction, and clear space.
- Never stretch, rotate, reflect, crop, outline, stroke, recolor, add effects, remove elements, or rearrange the logo.
- Never place the logo on a similar-value background that reduces recognition.
- Do not assume the monogram alone is approved for production; use it alone only when an official asset or explicit approval exists.
- Use dark ink on yellow for normal-size digital text. Avoid white body text on yellow because it does not provide reliable contrast.
- Use IBM Plex Sans Arabic across Arabic and Latin content unless the user explicitly approves another family.
- Keep lighting-product photography believable, architectural, warm, and premium. Avoid generic neon, cyberpunk, glassmorphism, or unrelated luxury motifs.

## Translate, do not merely decorate

Use the brand system to clarify product discovery and create a distinctive lighting experience. Favor a calm editorial structure with concentrated moments of yellow, charcoal contrast, precise line icons, and large product imagery. Let the product's light create the visual drama; do not cover every surface with brand yellow.

For catalog work, preserve the hierarchy and component guidance in [references/website-blueprint.md](references/website-blueprint.md). For any conflict, treat the original PDF and official production assets as authoritative.
