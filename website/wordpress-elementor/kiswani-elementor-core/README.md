# Kiswani Elementor Core

Custom WordPress plugin for the Elementor rebuild.

## Responsibilities

- Register editable Products, Projects, Orders, and Collections.
- Store product metadata required by the current Next.js website.
- Provide WordPress REST routes that replace the Next.js order APIs.
- Provide Elementor widgets for dynamic Kiswani sections.

## Initial Widgets

- `Kiswani Product Grid`

More widgets should be added during page-by-page implementation:

- Header mega menu
- Product map tabs
- Product single gallery/specs
- Cart drawer
- Checkout
- Order dashboard
- Project cards
- Contact drawer
