# Hello Kiswani Child

Elementor child theme for the Kiswani Lights pixel-matched WordPress rebuild.

## Purpose

This child theme is only responsible for presentation:

- Local IBM Plex Sans Arabic font loading.
- Global Kiswani color/spacing/interaction tokens.
- Elementor-compatible utility classes that mirror the current Next.js/Tailwind design.
- Lightweight UI JavaScript for language direction and drawer state.

Business logic, custom post types, product data, orders, REST routes, and Elementor widgets belong in the `kiswani-elementor-core` plugin.
